## Program minimalny (§73)
11 wymaganych funkcji uwzględniono: woda (studnie D02/03, twierdza), mieszkania (D01–03), żywność (D01/D05/dostawy D08), magazynowanie (D05/D07), handel (D01), kowalstwo (D04), karczma (D01), kult (D06), administracja (D06/D07), medycyna (D06), straż (D07 i posterunki bram). Edukacja (szkoła), biblioteka (łączona lub osobna), więzienie (opcjonalna funkcja w twierdzy), łaźnia/apteka/cech jako rekomendowane dodatki, nie wymogi §73. Port geograficzny — wyłączony D013. Arena, kasyno, odrębny sąd nie są konieczne; nie przesądzać braku przyszłej budowy. Źródło wody nie oznacza automatycznie wody pitnej z rzeki.
## Łańcuchy funkcjonalne
Zboże: dostawy → spichlerz → młyn (warunkowo dostęp do wody) → piekarnia → rynek/karczma. Drewno: dostawy → magazyn → stolarstwo → handel/budownictwo. Metal: import surowców/półproduktów → kuźnia → narzędzia/handel; nie zakładać kopalni/huty. Skóry: dostawy → garbarnia (warunkowa odbiór MTL i odseparowane zaplecze) → szewstwo → handel. To przyszłe zależności, nie działające mechaniki.
## Priorytety i zasady bilansu (04)
MDS §71 wzorzec średniego miasta: mieszkalne 55%, handlowe 12%, produkcyjne 12%, usługowe 8%, magazynowe 5%, instytucjonalne 8% zabudowanych standardowych parceli. Proponowane podejście: mieszkania priorytet, dostosować proporcje do handlu/rzemiosła bez obniżania pojemności; każda zabudowana parcela liczona raz wg dominującej funkcji. Funkcje drugorzędne osobno; nie liczyć straganów, publicznych placów ani twierdzy jako parceli P. Gospodarstwa i pola wg §17/22/70: pola poza mianownikiem, standardowe działki budowlane gospodarstw w bilansie, bez podwójnego liczenia. 24 wolne parcele naprawdę puste, rozproszone także w atrakcyjnych lokalizacjach; przeznaczenie nie stanowi nieodwracalnej blokady. Liczebności BDS, P1–P6, model/pojemność, korekty i warianty w 04; nie wszystkie kandydatury muszą wejść do 72. GDD §49 nie zwiększać liczby samodzielnych lokacji świata.
