# Trade and services expansion
16 new templates, 17 floors, 16 furniture and 14 prop types. Floor plans share a two-zone structural family with varied dimensions, partitions, room programs and furnishings; inn has upper floor. Service types map to existing shop/workshop BDS categories. Placement searched deterministically at design time; no runtime layout generation. Room functions derive from stations, not actual implemented trade/services. Shared renderer, gallery r7 review-only, older catalogues preserved. 64 rotated instances checked, approved-copy compile and viewer loader, mock canvas 64405 calls. No actual browser or mobile verification.
