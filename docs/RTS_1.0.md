# RTS 1.0 — Alpha 0.3.33.2

Topology, Access overlay and shared graphics delivered together. Structural walls and authored open edges define flood-fill components; furniture does not divide rooms. Open edges are not physical doors. Each component needs exactly one anchor; ambiguous/unassigned components and objects crossing boundaries are errors for RTS maps. Room membership includes furniture footprints. Available actions derive from actual stations and their approach zones, not just declared purpose. Room IDs, area, neighbors, objects, stations and portals available for inspection. Legacy ambiguous anchors remain anchors. No permission enforcement, physical internal doors, automatic remodeling or actual NPC reservations yet. Shared canvas renderer used for MFS interiors in game and viewer; preview does not publish a review map. No exterior graphics or final assets claimed. Gallery r3 and v3 catalog preserve older revisions. Tests: 37 rooms, 3039 cells, 58 open edges, 92 oriented instances, missing anchor/boundary rejection, 24 preview scenes, 61806 mock canvas operations, zero loader errors/warnings, syntax. No Android browser or visual verification.
